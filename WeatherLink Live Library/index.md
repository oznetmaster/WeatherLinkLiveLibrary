# WeatherLink Live Library

WeatherLink Live Library is a reusable .NET API client for querying a local WeatherLink Live device.

## What this site contains

- API documentation for the `WeatherLinkLive` client
- Overview material for the library and test harness
- Release and usage information for the published package

## Getting started

1. Build the solution.
2. Set `WEATHERLINK_LIVE_IP` or create `.local/weatherlink-live-ip.txt`.
3. Run the `WeattherLinkLive Test` console harness.
